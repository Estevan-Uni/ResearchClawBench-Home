# ResearchClawBench-Home

This branch contains **EvoLab's ResearchClawBench G1/G2 results** for all 40 tasks.
For 37 tasks, it selects the higher judge score from G1 and G2 (or the only
available G1 score). The remaining three tasks were blocked by agent safety
policy and are **assigned 0 points**, clearly marked as unevaluated by the judge.

Run records, reports, figures, code, per-attempt cost and time, and the 40-row
results table are under [submission/evolab](submission/evolab/README.md).
See the [submission status](submission/evolab/SUBMISSION_STATUS.md) for the
official ZIP and email procedure. GitHub publication is an archive of these
results, not an official leaderboard acceptance.
