# EvoLab ResearchClawBench submission archive

This repository contains EvoLab's G1/G2 results for all 40 ResearchClawBench tasks. The submission files are under [submission/evolab](submission/evolab/README.md), including the results table, score and cost records, reports, and figures.

The three safety refusals are marked as unjudged and assigned zero in this archive. The results use best-of-two selection where both G1 and G2 were scored. See [submission scope](submission/evolab/SUBMISSION_STATUS.md) for the distinction between this public archive and the maintainer's separate ZIP review process.
